# amane.JpBusiness

Verified Japanese business rules, calculations, and standards for .NET.

> Status: Early development

amane.JpBusiness is an open-source .NET project for reusable and verifiable Japanese business rules, calculations, and standards.

The project prioritizes explicit normative sources, reproducible rules, and executable test cases over feature count.

No production NuGet packages are published yet.

Development decisions are governed by [DEVELOPMENT_PRINCIPLES.md](./DEVELOPMENT_PRINCIPLES.md).
